## 📖 Overview

This repository documents a complete, structured laboratory curriculum in **Web Technology, HTML5, and Modern CSS3 Layout Architecture**. The projects range from core document structures, complex forms, and tables to advanced modern layout paradigms including **Flexbox**, **CSS Grid areas**, **2D geometric transformations**, and **positioning anchors**. 

The repository culminates in a complete **Amazon Clone** e-commerce landing page featuring a multi-tier navigation bar, responsive product category grids, and a multi-column footer.

## 🛒 Capstone Project: Amazon Clone

The `project/` directory contains a landing page clone of Amazon:
- **Global Header:** Amazon logo, deliver-to locator, search bar with category dropdown, accounts & orders menu, and shopping cart counter.
- **Secondary Sub-Navbar:** All-category hamburger menu, quick links (Today's Deals, Customer Service, Registry, Gift Cards, Sell).
- **Hero Section:** Full-width hero banner with promotional callouts.
- **Shop Grid Section:** 8 modular grid cards (Electronics, Fashion, Home Decor, Beauty, Pet Supplies, Gaming Accessories, etc.).
- **Footer Section:** "Back to top" anchor, multi-column company info links, country/region selector, and copyright credits.

## 💻 Running the Experiments Locally

Because these experiments are built with pure HTML5, CSS3, and standard JavaScript, **no package managers, build steps, or compilers are required**.

### Option 1: VS Code Live Server (Recommended)
1. Install the **Live Server** extension in VS Code.
2. Right-click on `index.html` (or any file in `lab1/` ... `lab11/` or `project/`).
3. Click **"Open with Live Server"**.

### Option 2: Python Built-in HTTP Server
```bash
# Clone the repository
git clone https://github.com/ritikthakur22/html5.git
cd html5

# Start local server on port 8000
python3 -m http.server 8000
```
Open `http://localhost:8000/` in your browser.

### Option 3: Node `npx serve`
```bash
npx serve .
```
